# Цветочная лавка — статический сайт

Простой одностраничный сайт каталога букетов с формой заказа.

## Запуск локально

Откройте файл `index.html` в браузере.

Либо поднимите простой сервер:

```bash
# Python 3
python3 -m http.server 8080 --directory /workspace/flowers-site
# Затем откройте: http://localhost:8080/index.html
```

## Структура

- `index.html` — страница
- `styles.css` — стили
- `script.js` — каталог, поиск/сортировка, отправка формы (мок)
- `assets/` — логотип и фавикон

## Кастомизация

- Обновите товары в массиве `products` в `script.js`
- Замените изображения и контакты в футере
- Подключите реальный бэкенд: замените мок-отправку в обработчике формы
